# The Project Photo Data Exploration 
---
 ## About
This project attempts to statistically compare different mediums of art and whether there is a correlation of "what is captured" visually between them. 

Mediums in this specific report are digital photography, analog collage and
analog photography (film).
---
## How To Run 
1. Run the project frome the main Folder
2. Your image data should be placed in folder ./Data/Raw and categorized into 
the "Film", "Digital", "Collage"
3. If you don't posses such data you can still run the analysis with already proccessed image data
that is placed in .Data/Processed/*.pkl
